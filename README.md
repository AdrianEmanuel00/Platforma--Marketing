# Platforma Marketing

Platformă de social media marketing bazată pe agenți AI, pentru afaceri mici și agenții (câte un proiect pentru fiecare client).

Agenți planificați:
- **Postare**: conectează conturile de social media, creează postarea, alegi platforma și publici.
- **Creative**: generează imagini și video, păstrând identitatea de brand a fiecărui business.
- **Research**: analizează zilnic trendurile și competitorii și propune idei.

Status: în planificare.
